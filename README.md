# Режаларим — вазифалар рўйхати

Кирилл ёзувидаги оддий вазифалар рўйхати. Build ёки сервер керак эмас: `index.html` ни браузерда очинг.

## Бўлимлар
- **Вазифалар** — қўшиш, таҳрирлаш, бажариш, қидириш, фильтрлар (бугун, кечиккан, келгуси, бажарилган). Ҳар вазифада муддат, муҳимлик, тоифа, тахминий вақт, изоҳ.
- **Календарь** — ойлик кўриниш, кунлик юклама чизиғи, кунлик соат лимити, кечиккан ишларни бугунга кўчириш.
- **Режа** — мақсад қўйиш ва йўл харитаси: муддатдан орқага қараб режалайди, ~15% захира қолдиради, кунлик лимит ва календардаги мавжуд юкламани ҳисобга олади. Натижани календарга қўшади.
- **Ҳисобот** — 7 ёки 30 кунлик баҳо (A–E), бажарилиш улуши, вақтида бажариш, фаол кунлар, тоифалар бўйича таҳлил ва тавсиялар.

## Баҳо формуласи
`60% бажарилган улуши + 25% вақтида бажарилиши + 15% фаол кунлар`. Фақат шу даврда муддати ўтган ёки бажарилган вазифалар ҳисобга олинади.

## Эслатма
Йўл харитаси ва тавсиялар қоидага асосланган ҳисоблаш, сунъий интеллект эмас. Маълумот браузернинг `localStorage` ида сақланади; «Нусха олиш» / «Тиклаш» орқали JSON сифатида сақлаш мумкин.
